# 掲載画像の出典

運営紹介では、にょっき・いけちゃんの好きなことを表す花・雪景色を掲載しています。画像の出典と利用条件を以下に記録します。

## にょっき / 白い花

- 作者：Ivan Fonin
- 生け花にちなむ花のイメージ。自作の生け花という表示はしていません。
- 元ファイル：`cc0-photo-9.JPG`
- 出典：https://github.com/ivanfonin/cc0-photos/blob/22be2e285db50193362e8ed06712b4146e714f6c/cc0-photo-9.JPG
- 利用条件：作者がREADMEでCC0公開を明記。記録は `assets/licenses/Ivan-Fonin-CC0.txt`。
- ローカルファイル：`hobby-flowers-480.webp` / `960.webp` / `1200.webp`

## いけちゃん / 雪景色

- スノボにちなむ雪山のイメージ。
- 配布元：Flutter Gallery Assets 1.0.2 / The Chromium Authors
- 元ファイル：`lib/crane/destinations/3.0x/fly_0.jpg`
- 配布ページ：https://pub.dev/packages/flutter_gallery_assets/versions/1.0.2
- 配布アーカイブ：https://pub.dev/api/archives/flutter_gallery_assets-1.0.2.tar.gz
- 利用条件：同梱LICENSEのflutter_gallery_assets節（BSD 3-Clause）。著作権表示・条件全文は `assets/licenses/Flutter-Gallery-Assets-LICENSE.txt` に同梱。
- ローカルファイル：`hobby-snow-480.webp` / `960.webp` / `1200.webp`

どちらも外部画像URLをサイトから呼び出さず、ローカルのWebPで表示します。サイズ調整と円形の切り抜き表示のみで、画像内の人物や顔の描き直しは行っていません。出典とライセンスは単一HTML版にもコメントとして同梱します。

## 追加の活動写真

ユーザー提供のアーカイブZIPから受け取ったラテアート・体験風景・交流会・フットサルの4枚を掲載しています。原本は `assets/originals/` に保持し、WebPの表示用コピーではEXIFを含めず、画素サイズのみ調整しています。写真内の人物・顔の加工や生成は行っていません。配置は `PHOTO-PLACEMENT.md` に記録しています。
